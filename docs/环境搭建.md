# 环境搭建 — 新机器（Kimi Code 桌面端工作区）

> 目标：在一台全新 Windows PC 上把项目跑起来，能改代码、跑测试、部署到 NAS。
> 前置：已安装 Git、Python 3.12+（勾选 Add to PATH）。

## 1. 安装 Kimi Code 桌面端并创建工作区

1. 下载安装 Kimi Code 桌面端，用 Kimi 账号登录（会员权益通用）。
2. 克隆仓库到**新目录**（不要直接复用旧机器的项目文件夹）：

```powershell
git clone https://github.com/haley242700/nexus-netms.git D:\nexus-netms
```

3. 打开 Kimi Code 桌面端 → 新建会话 → 工作区选择 `D:\nexus-netms`
   （或终端执行 `kimi app D:\nexus-netms`）
4. 新会话第一件事：让它读 `AGENTS.md` 和本文件。

## 2. Python 环境

```powershell
cd D:\nexus-netms
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
python manage.py test   # 离线全量测试，必须通过
```

## 3. 凭据与工具（git 里没有，从旧机器复制）

| 来源（旧机器） | 目标 | 说明 |
| --- | --- | --- |
| `config/secrets\` 整个目录（5 个 .env） | 同名路径 | 睿易 / NAS / 云端凭据，**绝不提交 git** |
| `tools\platform-tools\` 整个目录 | 同名路径 | 谷歌 adb 工具（也可从 google 官网重新下载 platform-tools） |
| `tools\ADBKeyboard.apk` | 同名路径 | 电视文本注入输入法 |

复制后验证：

```powershell
# 网关只读查询（能返回 JSON 即通）
PYTHONPATH=apps/speedtest-ap .venv\Scripts\python.exe -c "import os,sys; [os.environ.setdefault(*l.strip().split('=',1)) for l in open('config/secrets/login.env',encoding='utf-8') if l.strip() and not l.startswith('#')]; sys.path.insert(0,'apps/speedtest-ap'); from ap_lookup import ReyeeClient; print(len(ReyeeClient()._cmd('ap_list').get('list') or []), 'APs online')"

# NAS SSH（能输出即通）
PYTHONPATH=. .venv\Scripts\python.exe tools\nas\nas_ssh.py "hostname"
```

## 4. git 代理坑

本仓库在旧机器上配置了代理 `127.0.0.1:7892`，新机器若没有 VPN 客户端会推送失败：

```powershell
git -c http.proxy= -c https.proxy= push origin main
```

新机器可以直接 `git config --global --unset http.proxy` 清掉。

## 5. 部署链路验证

```powershell
python manage.py package all   # 生成 dist/ 部署包
```

NAS 目录对照见 README「NAS 重复部署」。NAS 生产服务正常时 `python manage.py verify` 做只读验证。

## 6. NAS 端（不需要重建的部分）

开发容器（code-server :8443）、生产容器（nexus 全套）、git 部署密钥都在 NAS 上，不随 PC 迁移变化。NAS 故障时的重建顺序见 README 与 `apps/dev-workspace/deploy-nexus.sh`。
